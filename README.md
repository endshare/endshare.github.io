# ENDSHARE · 最后共享

> 开放、共享、长期可用。

我们相信，数据与洞察不应被封闭在孤岛中，而应被持续采集、分析并归档，让更多人自由获取、复用与验证。

**主题：数据抓取 · 数据分析 · 数据归档**

## 🌍 我们是谁

ENDSHARE（最后共享）是一个致力于**开放数据基础设施**的开源组织。我们希望成为数据生命周期的“最后一站”——把散落在各处的公开数据采集下来，清洗分析，并长期归档，使其不因链接失效、站点下线或接口变更而消失。

我们的工作围绕三个关键词展开：

- **数据抓取**：以合规、可复现的方式采集公开数据
- **数据分析**：把原始数据转化为可理解、可验证的洞察
- **数据归档**：让数据在多年后依然可访问、可追溯

## 🧭 我们相信

- **数据应可获取**：公开数据不应被人为设障，而应被整理、索引、开放。
- **过程应可复现**：抓取脚本、清洗规则、分析逻辑全部开源，结果可被任何人验证。
- **成果应可复用**：数据以开放许可发布，鼓励二次创作与研究使用。
- **归档应可持续**：一次采集，长期保存，抵抗链接腐烂与平台变迁。
- **使用应守边界**：尊重隐私、遵守 robots 协议与相关法律法规，只处理公开、合规的数据。

## 🚀 如何参与

我们欢迎任何形式的贡献——不一定是代码。

- 🐛 **报告问题**：发现数据错误、链接失效或脚本缺陷，欢迎提 Issue
- 💡 **提出想法**：想要归档某个数据集？在 Discussions 里发起讨论
- 🔧 **贡献代码**：改进抓取脚本、分析流程或归档工具，欢迎 Pull Request
- 📚 **完善文档**：帮助补充数据说明、使用指南与许可信息
- 🌱 **复用成果**：用我们的数据做研究、做产品、做可视化，并告诉我们

参与前请阅读组织的 **贡献指南** 与 **行为准则**。

## 📦 项目约定

- 每个数据项目附带 `README`，说明**数据来源、采集时间、字段含义与许可**
- 抓取脚本与数据分离存放，便于复现与更新
- 优先使用开放许可（如 CC BY、CC0、MIT），并明确标注
- 归档数据保留**版本与校验信息**，确保可追溯

## ⚖️ 数据伦理

我们只采集**公开可访问**的数据，尊重站点条款与 `robots.txt`，不采集个人隐私信息，不绕过访问控制。若你认为我们的项目涉及不当数据，请通过 Issue 或邮件联系我们，我们会及时处理。
